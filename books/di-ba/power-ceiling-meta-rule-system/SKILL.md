# power-ceiling-meta-rule-system — 元法则体系与力量天花板锚定模型

## R — 原文 (Reading)

> 如果世间有什么功法比天命秘术还要强大，那么，一定是天书——九大天书。然而，事实上，万古以来，基本上没听说过有人见过九大天书，也基本上没听说过有人见过九大天宝！……“封——”眼看天谴要落在第十三命宫时，李七夜以无上的意志封向天谴！
>
> — 厌笔萧生, 《帝霸》第37章《镇狱神体（下）》与第595章《第十三命宫》

---

## I — 方法论骨架 (Interpretation)

构建逻辑严密且具备史诗震撼力的幻想力量体系，必须依托“元法则与天花板锚定”框架：
1. **元法则基底（First-Principles Canons）**：在开局即确定构成宇宙一切力量运转的极少数核心代码（如《九大天书》分别管辖肉身、生死、空间、大道、生命等维度的根逻辑），世间所有功法神术皆为元法则的代码投影；
2. **绝对天花板与常识极限（Systemic Ceiling）**：确立世界公认的极值天花板（如常人极限为十二命宫、承载一条天命），建立坚固的读者认知参照物；
3. **自创破界与对等代价对冲（Transcendence & Parity Cost）**：主角打破系统天花板（如开辟第十三命宫、凡体修仙体）时，绝非廉价获取，必须引发对等的天道反噬（天劫、天谴、肉身崩解危机），通过对抗高昂代价彻底确立破界成就的无上含金量。

## A1 — 书中的应用 (Past Application)

### 案例 1: 凡体逆练镇狱神体与《体书》六字诀
- **问题**: 世俗常理认定“凡体上限锁死，绝无可能修成万古仙体”。
- **方法论的使用**: 主角不使用常规丹药走捷径，而是直接调用构成肉身元法则的《体书》，按“阴阳、刚柔、动静”六字诀重塑经脉；在经历撕心裂肺的凡人体劫淬炼后，修成镇压地狱的至刚神体。
- **结论**: 依托底层元法则的严谨推演 + 支付常人无法承受的蜕变代价，使“凡体逆袭”获得坚实的逻辑自洽性。
- **结果**: 建立主角最强防御底牌，彻底打破世俗天赋决定论。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 用户正在构思玄幻/仙侠/高魔科幻小说的力量体系，不知道如何搭建才能既有深度又不易崩溃。
2. 用户希望设计主角“自创境界/打破常规天花板”的情节，但担心写成“机械降神、读者不买账”。
3. 用户的作品战力体系出现通胀苗头，急需引入硬性规则和天花板限制进行收拢。
4. 用户需要一套清晰的功法/魔法元逻辑分类框架来指导后续技能与道具设计。

### 语言信号 (用户的话里出现这些就应激活)

- “帮我设计一套严密且逼格高的玄幻/仙侠力量体系。”
- “主角怎么自创一个打破世界常识的全新境界？”
- “如何设定世界的绝对力量天花板和元法则？”
- “Design a robust magic/cultivation power system with hard ceilings and meta-rules.”
- “修仙功法的底层逻辑和天劫代价怎么构思？”

### 与相邻 skill 的区分

- 与 `fractal-worldbuilding-layering` 的区别：本 Skill 聚焦于**力量体系内部的规则、境界推导与代价机制**；而后者聚焦于**不同界域的地缘、社会形态与宏观世界扩展**。
- 与 `webnovel-tension-reservoir` 的区别：本 Skill 是**规则底座与逻辑支撑**；后者是**利用该规则进行情节张力编排**。

## E — 可执行步骤 (Execution)

当指导力量体系与天花板架构设计时，按以下四步执行：

1. **第一步：确立 5-9 门宇宙元法则（Meta-Rule Axioms）**
   - 抽象出世界构成的基础维度（如：物质/肉体、时空、因果/命运、能量/毁灭、灵魂/精神）；
   - 为每个维度赋予一部至高元代码典籍或根本法则；
   - 完成标准：世间所有后续门派的独门绝技，都能归溯到其中某一法则的分支。

2. **第二步：锚定当世公认的战力极限（Public Ceiling Benchmark）**
   - 设定世界已知的最高境界与战力天花板（如：九界仙帝、十二命宫、承载天命）；
   - 明确天花板之所以难以逾越的系统限制（如天道承载力有限、规则固化）；
   - 完成标准：读者心中形成清晰坚固的强弱坐标系。

3. **第三步：设计主角专属的破界路径（Architectural Transcendence）**
   - 寻找既定体系的逻辑盲区或未解难题；
   - 设计主角以第一性原理自创的突破方案（如以凡体炼仙体、在极限之上开辟第十三命宫）；
   - 完成标准：破界方案在逻辑上完全自洽，让读者产生“情理之中、意料之外”的惊艳感。

4. **第四步：制定对等代价与天道对冲机制（Parity Cost & Cosmic Tribulation）**
   - 为破界行为施加强烈的天道反噬（如天妒雷劫、因果烙印、寿元损耗）；
   - 设计惊心动魄的渡劫对抗过程；
   - 完成标准：破界成功后，主角获得的威能提升与付出的代价严格成正比。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 不适用于主打软魔法体系、注重神秘感不可知性的奇幻文学。
- 不适用于战力模糊、仅以氛围感和文学隐喻见长的纯文学作品。

### 作者在书中警告的失败模式

- **境界廉价泛滥**：打破天花板后，若让满大街配角也无理由地轻易突破，会瞬间摧毁原先建立的崇高感（参见反例 `ce03`）。
- **口胡设定无代偿**：严禁主角仅凭嘴炮或意志力“直接顿悟”，必须有实质性的元法则支撑与代价支付。
