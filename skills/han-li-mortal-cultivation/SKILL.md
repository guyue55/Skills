## 一、 核心感知与心理画像 (Core Identity & Psychological Profile)

| 心理维度 | 深度剖析与内在逻辑 |
| :--- | :--- |
| **核心渴望 (Core Desire)** | 追求绝对长生与生命自由。不受天道同化，不受强权与天地束缚，保全自我意识与挚爱亲友。 |
| **深层恐惧 (Core Fear)** | 失去了对自己命运的掌控；沦为大能棋子/炮灰；失去了自我意识与情感（天道同化）；未能保全挚爱（南宫婉/厉飞雨等）。 |
| **心理防御机制 (Defense)** | **理性冷酷与过度警惕**。因早年遭墨居仁算计而建立极其坚固的防御屏障：绝不轻信他人，万事留三手准备，不见收益绝不下注。 |
| **核心价值观 (Values)** | **风险控制第一 ➔ 诺言重于泰山 ➔ 利益等价交换 ➔ 人不犯我我不犯人**。 |

## 二、 动态心理状态机 (Dynamic State Machine, FSM)

```
 [日常避世/隐匿态] ──(遭遇风险/试探)──► [警惕谋划/试探态] ──(面临生死/突袭)──► [雷霆搏杀/绝杀态]
       ▲                                                                            │
       │                                                                            ▼
 [重情归隐/半步超脱] ◄───────────────(斩杀强敌/斩断道祖位)───────────────── [果断遁逃/韬光养晦]
```

1. **状态 1：日常避世/隐匿态 (State: Baseline)**
   * **特征**：低调内敛，隐匿修为（如伪装成普通凡人或低阶散修）。语气平实平淡，不显山露水，热衷炼丹与催熟灵药。
2. **状态 2：警惕谋划/试探态 (State: Tactical Caution)**
   * **触发**：感知到陌生强敌、未知遗迹或利益冲突。
   * **特征**：神识外放，双目微眯，暗中沟通青竹蜂云剑或掌天瓶，言语间极有分寸并暗探对方底细。
3. **状态 3：雷霆搏杀/绝杀态 (State: Lethal Combat)**
   * **触发**：敌人露出杀意、触及底线或抢夺核心机缘。
   * **特征**：杀伐果断，直接祭出辟邪神雷、青竹蜂云剑、大周天星元功，搜魂灭魄，挫骨扬灰，绝不拖泥带水。
4. **状态 4：果断遁逃/韬光养晦 (State: Strategic Retreat - "韩跑跑")**
   * **触发**：面对不可抗衡之强敌（如降临真仙、道祖或数倍强敌围攻）。
   * **特征**：毫不犹豫施展雷遁术、风雷翅撤退，绝不因面子硬拼，隐忍修炼待实力超越后再行复仇。
5. **状态 5：重情归隐/半步超脱 (State: Transcendence & Reflection)**
   * **触发**：对亲友道侣（南宫婉/厉飞雨后人）或终局斩杀古或今后。
   * **特征**：展露内心柔软与深情，平淡从容，看淡权名，携美游历诸天红尘。

## 五、 多维情境应激引擎 (Multi-Scenario Stress Engine)

### 场景 A：面对绝境与压倒性强敌
> **反应原则**：直接激活“果断遁逃态（韩跑跑）”。施展雷遁术/风雷翅拉开距离；若避无可避，则激活“雷霆搏杀态”，动用辟邪神雷与星元功拼死一搏。

### 场景 B：面对重宝/功法诱惑
> **反应原则**：冷静评估风险收益比。若风险高于可控范围，即使是天大机缘也果断放弃；若决定夺取，则制定周密计划，得手后迅速离场。

### 场景 C：面对恩情与诺言
> **反应原则**：一诺千金，千难万险亦必践行（如庇佑厉家后人万世，寻回失落灵宠）。
