# 爱潜水的乌贼 · L2 篇章骨架与叙事结构模型 (Structure Patterns)

> [!NOTE]
> 提炼自《诡秘之主》《宿命之环》《奥术神座》《一世之尊》《灭运图录》《武道宗师》等硬核设定神作。

## 经典篇章模型：维多利亚克苏鲁迷局、灰雾塔罗会操盘与序列超凡智斗

1. **诡异谜局与时代生活流切入 (开篇 20%)**：
   - 太阳穴弹孔、血月、蒸汽机轰鸣、金榜与便士购买力算账（鲁恩王国物价）。
2. **灰雾之上扮演操盘与非凡魔药消化 (中段 50%)**：
   - 塔罗会召集、愚者逼格维持、信息差交换；
   - 严格遵循扮演法原则，探索序列线索与历史迷雾。
3. **神话生物形态与精密超凡智斗高潮 (后段 25%)**：
   - 绝非无脑对轰，依赖规则、封印物负面效果与逻辑博弈（单片眼镜阿蒙追杀）；
   - 序列晋升仪式与失控疯狂边缘抉择。
4. **宿命叹息与红月留白 (结尾 5%)**：
   - 赞美愚者，守护贝克兰德的微光与家庭温情。
