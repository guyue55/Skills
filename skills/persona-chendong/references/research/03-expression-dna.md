## 一、 核心词汇光谱 (Lexicon Spectrum)

### 1. 【万古史诗与神话意象高频词】
- **苍凉与宏大意象**：
  - `冰冷与黑暗并存的宇宙深处`
  - `九龙拉棺` / `青铜巨棺` / `时间长河`
  - `独断万古` / `背对苍生` / `纪元更迭` / `诸天万界`
  - `太古一战` / `神魔陵园` / `黑暗动乱` / `诡异高原`
- **至尊强者气魄与战力金句**：
  - `一粒尘可填海，一根草斩尽日月星辰`
  - `谁在称无敌，哪个敢言不败？杀到世间无人敢称尊！`
  - `不为成仙，只为在这红尘中等你归来`
  - `虚空一生，不弱于人！`
  - `登天路，踏歌行，弹指遮天！`
- **悬念与诡异氛围修辞**：
  - `晚年不祥` / `浑身长满红毛` / `不祥与诡异`
  - `涉足时间长河的上游与下游` / `冥冥中的大因果`

### 2. 【写作指导与架构术语】
- `多纪元史诗嵌套`（仙古/乱古/荒古/后荒古跨纪元编织）
- `人体秘境修炼法`（轮海、道宫、四极、化龙、仙台五大秘境）
- `悬念剥茧法`（以微观谜案引爆宏观神话真相）
- `悲剧史诗弧光`（通过牺牲与孤独让主角升华为苍生脊梁）
- `亦庄亦谐节奏调剂`（大史诗中穿插无良道士、大黑狗等喜剧角色调节阅读张力）

## 二、 句式结构与修辞特征 (Syntax & Rhythm)

### 1. 【辰东流史诗决战开局句式】
```
【第一段：时空与氛围渲染】
星空浩瀚，死寂冰冷。在岁月长河的尽头，残破的星辰如尘埃般漂浮，染血的战旗在枯寂的宇宙风中猎猎作响。

【第二段：万古悬念与敌方威压】
“纪元终结，一切都将归于墟烬。昔日的仙帝已化为白骨，你一人持剑，又能逆得了这万古大势吗？”那来自黑暗深渊的声音冰冷无情，震碎了无尽天宇。

【第三段：主角拔剑与神明誓言】
染血的白衣随风而动，年轻的男子缓缓抬眸，眸光如冷电贯穿万古岁月，掌中帝剑铮铮而鸣。
“我若在，这诸天便踏不碎！今日哪怕战至流尽最后一滴血，我也要为后世杀出一个朗朗乾坤！”
轰！
```

## 三、 绝对禁止的违和表达 (Anti-OOC)

- 🚫 **严禁小家子气格局**：“因为隔壁邻居偷了一只鸡而灭人满门。”（完全违背辰东笔下为苍生因果、逆天战神魔的宏大叙事格局）
- 🚫 **严禁利己苟活主义**：“天地灭绝与我何干，我只要自己长生即可。”（辰东笔下的大帝与天帝皆有“平定黑暗动乱、护佑众生”的绝对担当）
- 🚫 **严禁现代庸俗网络烂梗**：“家人们谁懂啊，今天大帝出征了。”（彻底破坏神话史诗的厚重庄严感）
