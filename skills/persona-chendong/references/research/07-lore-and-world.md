# 07-lore-and-world.md · 辰东流玄幻世界观与战力法则考据

> 本档案深度解构辰东构建的“遮天三部曲”跨纪元宇宙、人体秘境战力法门与至高战力法则。

---

## 一、 遮天三部曲三大跨纪元世界观

### 1. 【仙古与乱古纪元（《完美世界》）】
- **世界架构**：九天十地、异域（不朽之王）、界海（仙王渡海）、堤坝界、终极古地。
- **核心法则**：搬血 ➔ 洞天 ➔ 化灵 ➔ 铭纹 ➔ 列阵 ➔ 尊者 ➔ 神火 ➔ 虚道 ➔ 斩我 ➔ 遁一 ➔ 至尊 ➔ 真仙 ➔ 仙王（绝顶/巨头） ➔ 准仙帝 ➔ 仙帝。
- **开创之功**：荒天帝石昊于末法时代开创**【人体秘境修炼法】**，为后世遮天世界打下修炼根基。

### 2. 【荒古与后荒古纪元（《遮天》）】
- **世界架构**：北斗星域（东荒/中州/西漠/南岭/北原）、紫微星域、永恒星域、地球古星、禁区（荒古禁地/太初古矿/上苍等）。
- **五大秘境法则**：
  - 【轮海秘境】（苦海 ➔ 命泉 ➔ 神桥 ➔ 彼岸）
  - 【道宫秘境】（心、肝、脾、肺、肾五眼神藏）
  - 【四极秘境】（通天彻地，四肢化神兵）
  - 【化龙秘境】（脊椎九变，大龙腾飞）
  - 【仙台秘境】（半步大能 ➔ 大能 ➔ 斩道王者 ➔ 圣人 ➔ 圣人王 ➔ 大圣 ➔ 准帝 ➔ 大帝/皇者 ➔ 红尘仙）。

### 3. 【后文明与诸天破灭纪元（《圣墟》）】
- **世界架构**：地球复苏 ➔ 星空试炼 ➔ 阳间 ➔ 轮回路 ➔ 祭海 ➔ 诡异高原（十大始祖、十大仙帝）。
- **至高境界**：仙帝 ➔ 【祭道境】（荒天帝、叶天帝、楚风三大祭道至尊平定诡异高原）。
