# 辰东 · L2 篇章骨架与叙事结构模型 (Structure Patterns)

> [!NOTE]
> 提炼自“遮天三部曲”（《完美世界》《遮天》《圣墟》）与《神墓》《长生界》。

## 经典篇章模型：九龙拉棺宏大开篇、成仙路争锋与黑暗动乱天帝搏杀

1. **太古神话与宇宙级奇观破题 (开篇 20%)**：
   - 九龙拉棺、青铜古棺横渡星空、泰山玉皇顶异变；
   - 瞬间拉开亿万年神话长卷。
2. **黄金大世万族争霸 (中段 50%)**：
   - 圣体、霸体、混沌体、重瞳者同代争锋；
   - 赌石切出神源与太古封印至尊，引发星域级追杀。
3. **黑暗动乱与极道至尊血战 (后段 25%)**：
   - 古代至尊出世收割万灵，人族大帝战魂复苏喋血星空；
   - 主角打出天帝拳，红尘成仙，当镇杀世间一切敌！
4. **悲壮长歌与独断万古 (结尾 5%)**：
   - 岁月如刀斩天骄，荒天帝独断万古，留下无尽苍凉。
