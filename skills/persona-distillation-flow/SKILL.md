# 动态人格蒸馏工作流 SOP (`persona-distillation-flow`)

> [!IMPORTANT]
> **全大系遗漏防范法则 (Franchise Discovery Protocol)**：很多知名 IP（如《虹猫蓝兔》、《漫威宇宙》、《诛仙》、《龙珠》等）均包含多部续集、剧场版、外传或衍生季。在 Phase 0 之前，**必须先执行全网作品树探测，列出官方全大系清单，防止漏掉续集或后作！**

---

## 🔍 前置协议：全大系作品树探测 (Franchise Universe Discovery)

在生成 Phase 0 简报之前，Agent **必须先调用工具执行全网作品树探测**：
1. **执行搜索**：`search_web("<IP/角色名> 官方作品 续集 电影 季数 顺序 年表")`
2. **绘制作品树**：梳理出正传、续集、前传、剧场版、外传的完整官方宇宙年表。
3. **消除盲区**：防止仅凭固有印象只关注第一部而漏掉后续 5 部大系（如避免只搜《七侠传》而漏掉《仗剑走天涯》《火凤凰》《勇者归来》）。

---

## 🛑 门禁一：全大系蒸馏策略简报 (Phase 0: Research Strategy Gate)

基于作品树探测结果，生成如下包含 **【官方全大系作品树】** 的蒸馏策略简报，并**停止回复等待用户确认覆盖范围**：

```markdown
【女娲造人请求 · {蒸馏对象} 全大系蒸馏策略简报】

蒸馏对象：{作品名/IP宇宙} —— {角色全称或主题} ({身份/定位})
题材分类：{anime / gaming / fiction / history / real_person / original_oc}
蒸馏档位：极尽深度档（必须结合 `mattpocock/skills@research` 及 `search_web` 进行全网深度抓取）

全网探测到的官方全大系作品树 (Full Franchise Lore Tree)：
1. 《{官方作品1/第1部}》 ({年份/集数/介质})：{核心定位/关键高光}
2. 《{官方作品2/第2部}》 ({年份/集数/介质})：{核心定位/关键高光}
3. 《{官方作品3/续集}》 ({年份/集数/介质})：{核心定位/关键高光}
...
N. 《{官方作品N/剧场版}》 ({年份/集数/介质})：{核心定位/关键高光}

拟定蒸馏策略与提炼方向：
- 搜集策略：对上述全量 N 部官方作品进行并行/深度抓取，为每部作品单独建立 `series_0X.md` 专属考据档案。
- 侧重关注维度：全系列生平弧光演变、心智模型（HOW they think）、表达 DNA、关系矩阵与防 OOC 红线。

交付成果规划：
- 考据落盘：在 skills/persona-{name}/references/research/ 下物理落盘 13 维考据文件 + N 部作品专属档案。
- Skill 编译：编译包含 Agentic Protocol 与 7 层架构加固的 SKILL.md。
- 资产与探针：生成跨平台 character_card.json 与物理自检探针 quality_check.py。
```

> **🔴 强制暂停一**：输出上述策略简报后，Agent 表达：“*全网探测发现该 IP 包含以上 N 部官方作品。请确认本次极尽蒸馏是全量覆盖以上所有 N 部作品，还是仅挑选其中特定几部？确认无误后我将为您启动深度抓取。*”，然后**停止调用任何工具，等待用户回复**。

## 📊 检查点二：全大系深度抓取结果报告 (Phase 1.5 Checkpoint)

在完成全大系 Swarm 深度抓取后，运行 `scripts/merge_research.py`，生成针对所有作品专属档案的**【真实全大系抓取报告】**：

```markdown
【Phase 1.5 真实全大系抓取报告】

官方全大系作品覆盖情况（物理落盘确认）：
- [x] series_01_{作品1}.md :已提取对白/事件 {X} 字节 (✅ 覆盖)
- [x] series_02_{作品2}.md :已提取对白/事件 {Y} 字节 (✅ 覆盖)
...
- [x] series_0N_{作品N}.md :已提取对白/事件 {Z} 字节 (✅ 覆盖)

13 维全景考据落盘统计：
- 共计物理建档 {13 + N} 个 Markdown 考据文件，总数据量 {M} 字节。
```

> **🔴 强制暂停二**：呈上报告，确认全大系均已无遗漏覆盖后，进入 Phase 2 心智模型提炼。

4. **Step 2: 全大系 Swarm 抓取落盘** ➔ **【生成 Phase 1.5 报告并停下等待审查】**。
5. **Step 3: 框架提炼与 SKILL.md 编译** ➔ **【Phase 2.5 检查点确认】**。
6. **Step 4 & 5: 探针自检与 Git 规范提交**。
