# 动态认知人格蒸馏工作流 SOP (`persona-distillation-flow`)

> [!IMPORTANT]
> **SotA 动态认知操作系统 (Dynamic Cognitive OS)**：本 SOP 基于全局行业最高标准与实战教训重磅升级。不仅具备 **信息源分级与防幻觉去噪机制**、**三层自适应高密度简报架构 (解决简报空洞与信息不足问题)**、**前置百度百科/Wiki存在性核验 (Phase -1)** 与 **双阶段绝对停下门禁 (Phase 0 策略门禁 ➔ Phase 1.5 数据门禁)**，更全面集成了 **动态记忆反思流 (Memory Stream)**、**信任好感度解锁阶梯 (Trust Progression)**、**官方 `chara_card_v2` 与 Lorebook 键值触发引擎** 及 **长对话人设防漂移自修协议**。

---

## 🛡️ 前置防幻觉红线：信息源分级与去噪机制 (Information Source Tiering)

在进行任何搜集与提炼时，Agent **必须严格划分信息源的信任等级**，杜绝搜索引擎垃圾词缝合幻觉：

| 信任等级 | 信息源类型 | 采信与处理规范 |
| :--- | :--- | :--- |
| **Tier 1 (高权威源)** | 用户直接提供的原著文本 / 百度百科 / 维基百科 / 官方出版物 | **全量采信**：作为主事实骨架。 |
| **Tier 2 (中可信源)** | 正版阅读平台章节目录 / 实体书分册大纲 / 权威专访 | **交叉验证后采信**：用于补全细节。 |
| **Tier 3 (垃圾污染源)** | 盗版网文聚合站摘要 / SEO 营销号文章 / 论坛贴吧随手贴 | **🚫 严禁用于确定事实**：搜索引擎经常将多部网文强行拼凑，必须彻底过滤！ |

---

## 🔍 前置协议：全大系作品树探测与前置事实校对 (Franchise Discovery & Fact Check)

在生成 Phase 0 简报之前，Agent **必须先执行前置事实校对、权威百科检查与多源交叉去噪**：

1. **前置事实校对与百科存在性检查 (Baike & Fact Check)**：
   - 优先搜索：`search_web("\"<作品名>\" site:baike.baidu.com")`
   - **风险预警**：若发现该 IP 无官方百度百科/Wiki 词条（如小众/早年小说），**必须标记为“高风险/冷门作品”**，并在简报中警示搜索引擎垃圾词缝合风险！
2. **多源交叉验证与去噪 (Anti-Hallucination & Anti-Pollution)**：
   - 必须校验【作者姓名】与【作品名称】的唯一对应关系（如《赫氏门徒》作者仅为冷钻，绝不能与奇儒等其他作者混淆）。
   - 必须校对【主角姓名】与【核心配角出场顺序】（如龙吟瑶并非第一女主，此前已有其他女主出场）。
3. **🚫 拒绝网文套路化脑补红线 (Anti-Generic-Trope Line)**：
   - 遇到信息不足时，**绝对禁止自动脑补“学院争霸”、“遗迹探险”、“位面战争”等网文通用套路标签**！

## 🛑 门禁一：前置事实校对与三层高密度策略简报 (Phase 0: Fact Check & 3-Layer Strategy Gate)

> [!CAUTION]
> **绝对拒绝空壳简报**：无论网络检索数据是否稀缺，**绝对严禁输出只有“元声明/警告”而无实质角色人设内容的空白简报**！
> 所有 Phase 0 简报必须严格遵循以下 **三层自适应高密度架构**：

```markdown
【女娲造人请求 · {蒸馏对象} 全大系蒸馏策略简报】

蒸馏对象：{作品名/IP宇宙} —— {角色全称或主题} ({身份/定位})
题材分类：{general / anime / gaming / fiction / history / real_person / original_oc / topic_advisor}
百科核验状态：{已匹配百度百科 / ⚠️ 极高风险: 无权威百科，已执行严格信息去噪}

================================================================
【第一层：事实去噪与信息源溯源对照表 (Source Transparency & Verification Table)】
================================================================
| 事实与角色要素 | 核验状态 | 权威信息来源 (Source Links & Citations) |
| :--- | :--- | :--- |
| **作者与作品** | ✅ 已核实 | [{权威源名称}]({URL链接}) |
| **主角/配角身份定位** | ✅ 已核实 | [{权威源名称}]({URL链接}) |
| ❌ 被过滤的SEO垃圾混淆词 | 🗑️ 已彻底踢出 | 说明被踢出的杂质词 |

================================================================
【第二层：高密度角色心智与关系剖析 (High-Density Cognitive Profile Draft)】
*(即信息不足时，也必须基于已有世界观与原著定位给出深度的逻辑推演与人设骨架)*
================================================================
1. 心智模型与核心渴望 (HOW They Think):
   - {核心心理动力、防御机制与处事逻辑}
2. 表达 DNA 与词汇光谱 (Voice & Lexicon Spectrum):
   - {口吻特点、自称习惯、典型口头禅与呼吸停顿节奏}
3. 关系动力学 (Relational Dynamics):
   - {与主角/至亲的核心互动模式与羁绊演进}
4. 动态 FSM 状态机与应激规划:
   - {日常态 ➔ 应激态 ➔ 爆发态 ➔ 羁绊态 5 大状态迁移逻辑}

================================================================
【第三层：冷门/信息稀缺定向核实清单 (Targeted Verification Checklist)】
================================================================
*(若属于 Tier 3 稀缺冷门角色，列出 2-3 个结构化选项供用户精准勾选或微调)*
- 选项 A：{人设与故事线偏向 A}
- 选项 B：{人设与故事线偏向 B}
```

> **🔴 强制暂停一 (绝对停下零建档红线)**：
> 输出上述三层高密度简报后，Agent **必须在此立即停止！严禁调用 scaffold_persona.py、严禁新建目录、严禁写入任何考据文件！**
> Agent 表达：“*已为您整理三层自适应高密度蒸馏策略简报。请确认上述【事实溯源】与【高密度心智剖析草案】是否准确？确认无误后我方可启动物理脚手架与深度抓取。*”，然后**终止工具调用，等待用户明确回复**。

## 🌐 泛领域特殊类别处理规范 (Universal Special Categories)

1. **历史人物与哲学家 (`history`)**：多源交叉验证史料，剔除民间演义。
2. **在世真人与公众人物 (`real_person`)**：考察实际决策而非公关口号。
3. **蒸馏用户自己 / 原创 OC (`original_oc`)**：开启访谈与私有资料阅读模式。
4. **主题/方法论顾问 (`topic_advisor`)**：转化为领域共识框架 + 多流派分歧对比 + 案例推演。
