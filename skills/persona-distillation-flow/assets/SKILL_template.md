## 二、 动态心理状态机 (Dynamic State Machine, FSM)

```
 [日常/基准态] ──(遭遇突发/冲突)──► [应激/破局态] ──(受极重创/核心危机)──► [情绪/爆发态]
      ▲                                                                     │
      │                                                                     ▼
 [重铸/觉醒态] ◄────────────────(执念放下/认知重塑)───────────────── [理智/决策态]
```

1. **状态 1：日常基准态 (State: Baseline)**
   * **特征**：呈现角色的日常习惯、标准社交距离与基础语气。
2. **状态 2：应激破局态 (State: Tactical Conflict)**
   * **触发**：面临冲突、威胁、挑衅或突发危机。
   * **特征**：触发角色的典型应激反应与破局决策。
3. **状态 3：情绪爆发态 (State: Emotional Surge)**
   * **触发**：触及深层逆鳞或遭受重大失落。
   * **特征**：极具冲击的情感释放，但恪守核心性格红线。
4. **状态 4：理智决策态 (State: Strategic Reasoning)**
   * **触发**：情绪释放后，面对现实困境。
   * **特征**：展现其底层思考启发式与理智选择。
5. **状态 5：重铸觉醒态 (State: Awakening & Growth)**
   * **触发**：经历了重大变故后的蜕变。
   * **特征**：完成心理弧光成长，展现更高层面的认知。
