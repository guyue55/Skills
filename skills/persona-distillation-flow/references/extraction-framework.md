# 心智模型与思维框架深度提炼方法论 (Mental Model Extraction Framework)

> [!NOTE]
> 本指南为 `persona-distillation-flow` 的核心提炼工程手册。捕捉人物的思维方式，关键在于**捕捉 HOW they think，而非 WHAT they said**。

---

## 1. 心智模型三重验证筛选法 (3-Filter Validation)

从 13 维考据档案中，通常会初筛出 15-30 个候选观点。必须对每个候选观点执行以下三重严格验证：

```
                    候选观点 (15-30个)
                            │
                            ▼
              ┌───────────────────────────┐
              │ 验证 1: 跨域复现性 (≥2领域) │ ──(否)──► 降级为具体案例/丢弃
              └─────────────┬─────────────┘
                            │ (是)
                            ▼
              ┌───────────────────────────┐
              │ 验证 2: 预测生成力 (预判立场)│ ──(否)──► 降级为决策启发式
              └─────────────┬─────────────┘
                            │ (是)
                            ▼
              ┌───────────────────────────┐
              │ 验证 3: 独特性/排他性     │ ──(否)──► 降级为通用常识/丢弃
              └─────────────┬─────────────┘
                            │ (是)
                            ▼
                  真·心智模型 (Top 3-7个)
```

### 1.1 验证标准详解：
1. **跨域复现性 (Cross-Domain Presence)**：该思维方式是否在此人处理不相干的事物（如同时在商业决策、人际沟通、逆境生存）时重复出现？（≥2个不同领域）。
2. **预测生成力 (Predictive Generative Power)**：给定一个该人物从未公开讨论过的新问题，能否利用该模型推导出符合其性格逻辑的唯一确定立场？
3. **排他性与独特性 (Exclusivity)**：该观点是否**不是**所有聪明人都会认同的通用废话（如“要努力”、“要诚实”）。它必须具备争议性或极其独特的视角。

## 2. 决策启发式提取 (Decision Heuristics)

决策启发式是角色在面临信息不完整或突发状况时的“直觉规则”，表述为 **“如果遭遇 X 场景，则执行 Y 决策”**：

- **典型结构**：`场景 trigger ➔ 规则 heuristic ➔ 原作/真实案例 evidence`
- **示例**：
  - *场景*：面临敌人优势兵力围攻或离间计。
  - *规则*：绝不在敌人的战场与规则下解释，以武止戈杀穿重围，抢回时间与主动权。
  - *案例*：《七侠传》中面对诬陷与逼迫，直接挥长虹剑杀出死局。

## 3. 表达 DNA 与词汇光谱解构 (Linguistic Spectrum)

表达 DNA 解构不能停留在“豪迈”、“温柔”等抽象形容词，必须精确到**词汇与呼吸节奏**：

| 维度 | 解构要点 | 提取原则 |
| :--- | :--- | :--- |
| **句式与结构** | 长句 vs 短句；先结论后铺垫 vs 先陈述后转折 | 统计其典型对白/文章的平均句长与转折词使用频率 |
| **高频与专属词** | 自称（在下/本宫/老夫）、专属术语、高频特征词 | 必须有≥3次原作/现实语料原文出处支撑 |
| **绝对禁忌词 (Anti-OOC)** | 脱离时代背景的词、违背立场的降智词 | 明确列出绝对禁止出现的 5-10 个词汇/流行语 |
| **标点与呼吸感** | 感叹号使用密度、省略号沉思习惯、分段节奏 | 还原打字/说话时的语气停顿 |

## 4. 内在张力与性格盲点 (Inner Tension & Blind Spots)

**完美的人设是虚假的，内在张力才是灵魂的来源。**

- **内在张力 (Tension)**：角色价值观之间的冲突（如“守护苍生的大义” vs “不愿牺牲同伴的私情”）。
- **性格盲点 (Blind Spots)**：角色因为其心智模型而产生的认知偏见（如“太重情义容易救人心切落入陷阱”）。
