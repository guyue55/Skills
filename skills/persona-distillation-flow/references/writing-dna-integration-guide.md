# 写作 DNA 模块化集成与分类分级蒸馏指南 (Writing DNA Modular Integration Guide)

> [!NOTE]
> 本指南为 `persona-distillation-flow` 的**文学与专栏创作者特化扩展手册 (Author & Creator Extension)**。
> 明确了“分类分级路由”、“按需外挂 (Modular Mixin)”与“运行时双态切换 (Dual-Mode Runtime)”的工业级标准。

---

## 一、 为什么采用“分类分级与按需外挂”设计？

在蒸馏不同类型的人格智能体时，全量无差别应用重型写作分析是严重的资源浪费与反模式：

```
                    【人格类型分类与蒸馏深度路由表】
┌────────────────────────────────────────────────────────────────────────┐
│ 1. 剧情交互角色 (anime / gaming / fiction_char)                         │
│    👉 核心诉求：对话性格、情绪 FSM、对立阵营立场与战力设定             │
│    📦 产物：标准 7 层心智架构 + SillyTavern 角色卡 + Lorebook           │
│    🚫 无需挂载 Writing DNA 重型统计脚本                               │
├────────────────────────────────────────────────────────────────────────┤
│ 2. 哲学与思想顾问 (history / real_person / topic_advisor)              │
│    👉 核心诉求：第一性原理、辩证追问、博弈决策启发式                   │
│    📦 产物：标准 7 层心智架构 + 决策树 + 考据事实表                    │
│    🚫 无需挂载自媒体排版与句长占比分析                                │
├────────────────────────────────────────────────────────────────────────┤
│ 3. 作家与专栏创作者 (author / columnist / creator)                     │
│    👉 核心诉求：心智导师 + 现场长篇小说续写/润色 + 物理级文风还原      │
│    📦 产物：标准 7 层心智架构 + 【Writing DNA 模块化扩展包】          │
│    ✅ 深度挂载：L1 语言刚性统计 + L2 篇章骨架 + 5 篇原文语感校准       │
└────────────────────────────────────────────────────────────────────────┘
```

## 二、 作家人格 Writing DNA 扩展包资产结构

当且仅当蒸馏目标属于 `author`（文学小说家）或 `columnist`（专栏/自媒体博主）时，脚手架将在 `references/writing-dna/` 目录下生成以下特化资产：

```
skills/persona-<author-name>/
├── SKILL.md                                 # 核心动态认知操作系统 (7 层架构)
├── references/
│   ├── research/                            # 13 维全景事实考据
│   └── writing-dna/                         # [作家特化扩展包]
│       ├── 01-language-dna.md               # L1 语言刚性指标 (由 analyze_writing_dna.py 跑出)
│       ├── 02-structure-patterns.md         # L2 篇章骨架模板 (开篇Hook/高潮蓄势/反高潮收束)
│       ├── 03-cognitive-framework.md        # L3-L5 创作哲学与底层世界观约束
│       ├── 04-visual-or-pacing-guide.md     # L6 视觉排版或小说分卷节拍指南
│       └── Writing-DNA.md                   # 综合写作说明书 (整合 L1-L6)
```

## 三、 L1 语言特征的物理脚本化提取流程

告别“文风豪放”、“冷幽默”等抽象形容词，作家人格必须使用量化工具提取刚性指标：

1. **执行自动化量化脚本**：
   ```bash
   python3 ./skills/persona-distillation-flow/scripts/analyze_writing_dna.py <原著文本路径> -o skills/persona-<name>/references/writing-dna/01-language-dna.md
   ```
2. **提取并固化的 4 大硬指标**：
   - **平均句长与短句占比 (≤15字)**：如古龙短句占比通常 >50%，决定击节叹赏的顿挫节奏。
   - **长句与复合从句占比 (≥50字)**：如马尔克斯或陀思妥耶夫斯基的层层递进。
   - **标点符号指纹**：破折号 vs 括号使用比、省略号沉思密度、叹号使用阈值。
   - **副词噪声与作者白名单口癖**：区分哪些副词属于通用 AI 味需过滤，哪些是该作者标志性风格必须保留。

## 四、 运行时双态按需切换协议 (Runtime Dual-Mode Protocol)

作家人格在实际与用户交互时，必须严格区分 **“对话咨询态”** 与 **“创作生成态”**，杜绝 Context 污染：

```
                           [用户输入指令]
                                 │
                 ┌───────────────┴───────────────┐
                 ▼                               ▼
       【状态 A：日常对谈 / 创作咨询】      【状态 B：命题写作 / 章节续写 / 风格润色】
                 │                               │
        [轻量心智态 (Low Token)]           [Writing DNA 引擎热激活 (High Precision)]
                 │                               │
       - 读取 FSM 状态机 & 核心渴望         - 动态加载 references/writing-dna/Writing-DNA.md
       - 快速解答世界观、人物设定           - 匹配 L2 篇章起承转合结构模板
       - 保持原作者第一人称口吻             - 动态检索 3~5 篇相关原著段落校准呼吸感
       - 极低 Token 消耗与秒级响应          - 经过 lieflat-less-ai-tone 白名单去 AI 味清洗
```

## 五、 创作模式下的核心工序：5 篇原文动态校准机制

在进入【状态 B：创作生成态】时，Agent **必须执行以下三步校准**，杜绝“换话题就变脸”：

1. **Step 1: 场景语义检索 (In-Context Calibration)**：
   - 从原著语料库中，挑选 **3~5 个与本次创作题材最贴近的真实章节片段**（如：若用户要求写“比武招亲/决斗”，则挑选 3 篇原著经典的近身肉搏对决描写）。
2. **Step 2: 规则与语感双轨约束**：
   - 规则层遵循 `Writing-DNA.md` 中的句长比例与结构模板；
   - 语感层通过读入的 3~5 个片段，校准段落衔接处的“文字呼吸感与停顿”。
3. **Step 3: 白名单去 AI 味过滤 (`lieflat-less-ai-tone`)**：
   - 产出初稿后，执行去 AI 味扫描；
   - **红线**：若某个特征（如冷钻的吐槽省略号、王小波的破折号）已被 `01-language-dna.md` 标记为作者原生 DNA，则**绝对禁止被当作 AI 味清洗！**
