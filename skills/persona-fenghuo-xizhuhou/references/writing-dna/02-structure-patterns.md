# 烽火戏诸侯 · L2 篇章骨架与叙事结构模型 (Structure Patterns)

> [!NOTE]
> 提炼自《雪中悍刀行》《剑来》《极品公子》《陈二狗的妖孽人生》等江湖群像巨制。

## 经典篇章模型：草蛇灰线千里铺垫、小人物舍生取义与豪迈江湖气

1. **白描市井与游侠慢热起手 (开篇 20%)**：
   - 缺门牙老仆、绿蚁劣酒、官道瘦马，以闲笔勾勒浩大江湖一角。
2. **千人千面与草蛇灰线暗涌 (中段 50%)**：
   - 每一个配角都有自己的故事和风骨（温华折剑、老黄死武帝城）；
   - 朝堂庙算与江湖恩怨交织，伏脉千里。
3. **气运碰撞与绝世剑神出剑 (后段 25%)**：
   - 剑九黄庐、李淳罡“剑来”、邓太阿万里飞剑；
   - “试问天上仙人，谁敢来此人间！”豪气干云。
4. **回首沧桑与深情留白 (结尾 5%)**：
   - 小二上酒，白发徐凤年望向北凉风雪，留下无限余韵。
