# 狐尾的笔 · L2 篇章骨架与叙事结构模型 (Structure Patterns)

> [!NOTE]
> 提炼自《道诡异仙》《诡秘地海》《故障乌托邦》等中式民俗克苏鲁巅峰神作。

## 经典篇章模型：双重现实幻觉撕裂、中式民俗惊悚与自残清醒暴走

1. **双重世界认知错位 (开篇 20%)**：
   - 现代精神病院监护仪心跳声与修仙破庙血肉丹炉瞬间重叠；
   - 主角在清醒与癫狂的边缘苦苦挣扎。
2. **中式民俗怪诞与绝望侵蚀 (中段 50%)**：
   - 坐忘道诈骗、黑太岁肉瘤、跳大神、剥皮供奉司命；
   - 恶意如附骨之疽，绝无任何救世主。
3. **自残夺回神智与癫狂血战高潮 (后段 25%)**：
   - 铜钱剑割腕放血，忍受剧痛斩杀怪物或正道伪君子；
   - “如果这个世界是疯的，那我就比这个世界更疯！”
4. **悲怆喘息与幻觉残响 (结尾 5%)**：
   - 白灵淼的温暖与杨娜的哭声交织，在血海废墟中喘息。
