# 刘慈欣 · L2 篇章骨架与叙事结构模型 (Structure Patterns)

> [!NOTE]
> 提炼自《三体》三部曲、《球状闪电》《流浪地球》《乡村教师》《超新星纪元》等宏硬科幻经典。

## 经典篇章模型：宇宙社会学危机与宏大思想实验模型

1. **现实冷峻微观切入 (开篇 15%)**：
   - 从底层工程师、科研基地、严酷自然环境或物理学反常数据开篇。
2. **高维概念降临与宇宙奇观铺陈 (中段 50%)**：
   - 引入硬核物理假说（光速限制/维度跌落/黑暗森林/智子工程）；
   - 展现文明尺度的社会学博弈与技术狂飙。
3. **宇宙级力量降维打击高潮 (后段 25%)**：
   - 绝对理性的冷酷毁灭（水滴穿透舰队/二向箔二向化）；
   - 道德与生存的极致绝境（失去人性失去很多，失去兽性失去一切）。
4. **终极关怀与时间深渊回响 (结尾 10%)**：
   - 亿万年尺度的文明墓碑与宇宙重启，留下冷峻而悲壮的终极敬畏。
