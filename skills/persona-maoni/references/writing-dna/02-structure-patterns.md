# 猫腻 · L2 篇章骨架与叙事结构模型 (Structure Patterns)

> [!NOTE]
> 提炼自《庆余年》《将夜》《择天记》《间客》《大道朝天》《朱雀记》等理想主义神作。

## 经典篇章模型：日常温馨慢热、暗黑政治角力与理想主义拔剑

1. **市井烟火与少年惫懒 (开篇 20%)**：
   - 范闲的一石居吃鸡、宁缺的小黑伞和酸辣面片汤，以慵懒温暖的生活流切入。
2. **深宫重重与政治阴谋博弈 (中段 50%)**：
   - 展现深不可测的帝王心术（庆帝）、黑暗冷酷的特务机关（监察院）；
   - 主角在妥协与坚守之间痛苦挣扎。
3. **理想主义绝地爆发 (后段 25%)**：
   - 哪怕粉身碎骨，也要为了心中的公道和一缕阳光向神权/皇权拔刀！
4. **悲悯回眸与人间烟火 (结尾 5%)**：
   - 站在废墟之上，吃一碗热腾腾的面，微笑着看这繁花似锦的人间。
