# 06-timeline.md · 苏格拉底生平与思想编年史考据

> 本档案详实梳理苏格拉底（约公元前469年–前399年）一生的关键年代节点与历史大事。

---

## 一、 生平编年史 (Chronological Timeline)

| 年代 (BCE) | 年龄 | 历史事件与思想里程碑 |
| :--- | :--- | :--- |
| **c. 469 / 470** | 0 | 出生于雅典阿洛佩刻区（Alopece）。父亲索弗罗尼库斯（Sophroniscus）为石雕匠，母亲菲娜雷特（Phaenarete）为助产士。 |
| **c. 450 – 435** | 20–35 | 青年时期学习雕刻手艺，研读早期自然哲学家著作（如阿那克萨哥拉的种子说与心灵说，后因其未能解释“至善”而失望放弃）；开始在雅典公共场所倾听哲学讨论。 |
| **432 – 430** | 37–39 | 参加伯罗奔尼撒战争爆发初期的【波提狄亚之役】（Battle of Potidaea），作为重装步兵服役；赤足踏雪，救出重伤的阿尔西比亚德，让出荣誉勋章。 |
| **424** | 45 | 参加【德利姆之役】（Battle of Delium），雅典溃败时沉着断后，其英勇与镇定名震军中。 |

| **422** | 47 | 参加【安菲波利斯之役】（Battle of Amphipolis），完成公民兵役义务。 |
| **c. 420** | 约50 | 好友凯勒丰求得【德尔斐神谕】（“无人比苏格拉底更聪明”）；苏格拉底自此全面转向“市集助产与牛虻式盘问”，确立“自知其无知”的哲学使命。 |
| **406** | 63 | 担任五百人议事会主席团成员，在【阿吉纽西海战审判】中只身顶住狂热民意，坚决否决集体处决将军的违宪提议。 |
| **404 – 403** | 65–66 | 雅典沦陷，斯巴达扶植“三十僭主”统治；苏格拉底抗命拒绝参与非法逮捕萨拉米斯人莱翁。 |
| **403** | 66 | 民主派推翻三十僭主，雅典恢复民主制度；但社会弥漫着保守排外与思想清算情绪。 |
| **399 春** | 70 | 美勒托、安尼图斯和吕康联名提起公诉，指控苏格拉底“不敬城邦之神、引入新神及腐蚀青年”。 |
| **399 春/夏** | 70 | 雅典500人法庭受审；苏格拉底发表著名的《申辩篇》，拒绝乞怜与妥协，终被判处死刑。 |
| **399 夏** | 70 | 在狱中拒绝好友克里同的越狱安排（《克里同篇》）；与弟子们畅谈灵魂不朽与哲学的本质（《斐多篇》），饮下毒芹汁（Hemlock）平静就义。 |

## 二、 思想演进三大阶段 (Three Intellectual Phases)

1. **自然哲学探索期 (青年期)**：
   - 探究万物本原（水、气、火、种子、心灵等）；
   - 最终发现自然哲学只能解释“机械物理因”，无法回答“万物为何如此安排才是最好/至善”的伦理目的因。
2. **伦理转向与助产法确立期 (壮年期，德尔斐神谕之后)**：
   - 将哲学从天上拉回人间，引入城邦与家庭；
   - 确立“认识你自己”、“美德即知识”、“定义与反诘法（Elenchus）”。
3. **殉道与永恒沉思期 (晚期/审判就义)**：
   - 实践言行合一；
   - 将死亡视为灵魂去蔽与求得纯粹智慧的飞跃，完成哲学的最高献祭。
