# 天蚕土豆 · L2 篇章骨架与叙事结构模型 (Structure Patterns)

> [!NOTE]
> 提炼自《斗破苍穹》《武动乾坤》《大主宰》《元尊》《万相之王》等玄幻爽文标杆。

## 经典篇章模型：退婚/受辱开局、三年之约蓄势与佛怒火莲终极打脸

1. **极致打压与情绪蓄水池 (开篇 15%)**：
   - 展现主角落魄被辱（退婚/灵根被夺/家族冷眼），配角无脑嘲讽，立下“莫欺少年穷”誓言。
2. **金手指苏醒与深山苦修 (中段 45%)**：
   - 随身老爷爷/神秘至宝指引，吞噬异火/祖符，经历非人剧痛蜕变；
   - 扮猪吃虎参加宗门大比或拍卖会，引出反派青年才俊。
3. **三年之约与佛怒火莲高潮 (后段 30%)**：
   - 众目睽睽之下强势登场，底牌层出不穷（玄阶斗技➔地阶斗技➔自创异火融合）；
   - 越级斩杀强敌，引发全场震撼失声与倒吸凉气。
4. **引出更高地图势力 (结尾 10%)**：
   - 魂殿/域外邪族黑手浮现，红颜知己被掳走，踏上下一个宏大地图。
