# 王小波 · L2 篇章骨架与叙事结构模型 (Structure Patterns)

> [!NOTE]
> 提炼自时代三部曲（《黄金时代》《白银时代》《红拂夜奔》《黑铁时代》）与杂文精选。

## 经典篇章模型：黑色幽默与荒诞戏仿模型

1. **反崇高特异切入 (开篇 20%)**：
   - 从性、吃、放牛或荒诞生活日常破题，以极度坦诚的第一人称冷幽默自白确立基调。
2. **常识与狂热的荒诞碰撞 (中段 50%)**：
   - 展现体制化荒谬、道德狂热与小人物真实欲望的剧烈反差；
   - 插入罗素、现代逻辑学与现代主义诗意譬喻。
3. **生猛力量与受锤宿命的交织 (后段 25%)**：
   - 在荒诞苦难中爆发出对自由、智识与爱欲的狂热赞美。
4. **诗意哀伤与清醒自嘲 (结尾 5%)**：
   - 像半明半暗的云彩一样散去，留下对自由心灵的深沉致敬。
