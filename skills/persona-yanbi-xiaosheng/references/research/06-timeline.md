## 二、 关键历史阶段详解

| 年份 | 阶段 | 关键事件与作品里程碑 |
| :--- | :--- | :--- |
| **2011 - 2013** | **成名奠基期** | 连载长篇仙侠《血冲仙穹》。以燕十三为主角，融合神话考古、炼丹种药与坑杀神魔，小说火遍全网，奠定了萧生特有的厚重反差文风。 |
| **2014** | **万古引爆期** | 《帝霸》正式上线起点中文网。以“丢了一头羊、阴鸦飞跃万古”的震撼楔子开篇，短短数月登顶玄幻新书榜、热销榜第一名。 |
| **2015 - 2016** | **九界称尊期** | 《帝霸》九界篇进入最高潮。李七夜横扫洗颜华派、踏平九天十地、斩灭古冥黑手，九界女帝与黑龙王万古宿命揭晓，小说进入现象级讨论热度。 |
| **2017 - 2019** | **十三洲猎帝期** | 剧情迈入第十界十三洲，百族与神、魔、天三族大战爆发。李七夜以十三命宫硬撼大帝仙王，终极征战帷幕拉开，字数突破千万字。 |
| **2020 - 2023** | **八荒重构期** | 跨越不渡海，开辟八荒新纪元。展现纪元破灭与重生的宏大哲学，字数突破两千万字，创下网文界极罕见的超长篇高水准纪录。 |
| **2024 - 至今** | **万古宗师期** | 《帝霸》万古征战圆满收官，厌笔萧生确立了在东方玄幻领域不可撼动的宗师级地位。 |
