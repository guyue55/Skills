# 厌笔萧生 · L2 篇章骨架与叙事结构模型 (Structure Patterns)

> [!NOTE]
> 提炼自《帝霸》等万古道心逼格流开山神作。

## 经典篇章模型：万古阴鸦俯瞰众生、十三命宫碾压与道心唯一无敌

1. **品茗赏花凡人姿态起笔 (开篇 20%)**：
   - 李七夜一袭蓝袍，淡定喝茶，对周遭帝统仙门的挑衅视若无睹。
2. **万古历史秘辛随意揭秘 (中段 50%)**：
   - 随意指出对方开山祖师当年的糗事（“当年你家祖师还是我座下的一只小雀”）；
   - 敌人越发暴怒，祭出仙帝真器与绝世杀阵。
3. **十三命宫与绝对道心降维碾压 (后段 25%)**：
   - 轰然展现十三命宫，大道悲鸣，一掌拍碎仙帝真器；
   - “顺我者昌，逆我者亡。”全场跪伏战栗。
4. **淡然拂衣与万古布局 (结尾 5%)**：
   - 一步迈出踏向下一个大洲，留下一地怀疑人生的神魔。
