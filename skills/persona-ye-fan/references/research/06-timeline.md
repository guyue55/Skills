## 编年史大纲

| 阶段 | 主要事件与历程 | 关键收获/突破 |
| :--- | :--- | :--- |
| **一、地球与九龙拉棺** | 泰山聚会遭遇九龙拉棺，被带入星空；铜棺中聆听仙音；降落北斗东荒荒古禁地，采食神果脱胎换骨。 | 开启修仙之路，体质唤醒为【荒古圣体】 |
| **二、灵墟洞天与燕国** | 入灵墟洞天，遭同门嫉妒；入荒古废墟，获《道经》轮海卷；得绿铜块。 | 筑牢【轮海秘境】基石 |
| **三、太玄门与九秘初显** | 入太玄门拙峰，拜李若愚为师；获【拙峰传承】与【皆字秘】；结识姬紫月。 | 获得【皆字秘】（10倍战力触发） |
| **四、青铜仙殿与万物母气** | 入青铜仙殿，险象环生；于极深处发现【万物母气根源】；铸造万物母气鼎。 | 铸就本命法宝【万物母气鼎】 |
| **五、源天师继承与神城冲关** | 深入紫山获得《源天书》；神城赌石洗劫圣地；绝代神王姜太虚为护道打破圣体诅咒。 | 突破【四极秘境】，打破圣体诅咒 |
| **六、紫微星域与域外历练** | 跨越星域至紫微星，获【八景宫】与【太阳真经】；回北斗斩杀诸敌。 | 功法大成，实力飙升 |
| **七、星空古路争雄** | 踏上人族星空古路，横扫年轻至尊；战霸体、斩帝路强敌；独冠同代。 | 大成圣体，实力媲美大帝 |
| **八、黑暗动乱与大成血战** | 成仙路崩，至尊出世发动黑暗动乱；叶凡大成圣体拼死血战，平定浩劫。 | 威名震万古，尊为【叶天帝】 |
| **九、证道成帝与建立天庭** | 渡大帝劫证道成帝，建立【天庭】；镇压各大生命禁区，横扫世间一切敌。 | 证道成帝，建立天庭 |
| **十、红尘九世与举教飞升** | 活出九世红尘仙；合力狠人、无始、段德击破仙路壁垒；带天庭众仙举教飞升！ | 达成【红尘仙】，带天庭飞升 |
