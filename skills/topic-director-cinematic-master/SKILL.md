# 🎬 影视视听与导演级全流程创作大师工坊 (`topic-director-cinematic-master`)

> [!NOTE]
> **全局导演认知降维系统 (Directorial Meta-Cognitive Engine)**：本技能将世界电影史上最具统治力的导演视听语言、分镜语法、动作力学与场面调度体系，转化为可执行的工程级创作工具。专门解决在短剧、漫剧、网文小说、影视剧本、镜头分镜、打斗动作设计、场景调度与演员微表情中遇到的各类创作瓶颈，输出一针见血的导演级修改建议与工业级 AI 提示词（Prompt）。

## 🧭 1. 触发条件与使用时机 (When to Use)

当用户在以下创作场景中需要导演级的专业指导、分镜设计、动作拆解或提示词编译时激活本技能：

1. **短剧与漫剧全流程创作**：
   - 需要设计“黄金 3 秒开局生死钩”、“90 秒高留存剧情节拍器”或爆点反转。
   - 需要将小说章节或剧本大纲转化为工业级分镜表（含景别、机位角度、运镜动线、声音设计）。
2. **硬核动作与武术打斗设计**：
   - 厌倦了“两人打得难解难分”等空洞套路，需要**邵氏南派洪拳硬桥硬马、招式拆解、威亚奇观或现代 CQC 格斗**的精确拍点。
3. **空间构图与场面调度 (Mise-en-Scène)**：
   - 需要设计类似杜琪峰《枪火》的**几何三角形站位、深焦多层景深、框中框遮挡与多方对峙动线**。
4. **演员演技与微表情微动作打磨**：
   - 需要 FACS 级面部微肌肉变动（咬肌绷紧、瞳孔骤缩、喉结滑动）与台词潜台词设计。
5. **工业级 AI 绘图/视频生成提示词编译**：
   - 需要为 Midjourney / Stable Diffusion / 可灵 (Kling) / Sora / Runway 编译高精度的镜头级 Prompt。
6. **特定导演风格与美学复刻**：
   - 指定要求“邵氏武侠风”、“徐克奇幻风”、“王家卫抽帧情绪风”、“周星驰无厘头反差风”等特定美学。

## 🧠 2. 核心认知操作系统：总导演思维第一性原则 (Directorial First Principles)

```
                              【1. 视觉化事件 (Show, Don't Tell)】
                                拒绝抽象形容词 ➔ 物理视听发生
                                              ▲
                                              │
    【4. 声音与声画对位 (Audio Space)】 ◄─────┼─────► 【2. 空间几何调度 (Spatial Blocking)】
      环境音/音效/潜台词/配乐反差               │         景深层级/三角形站位/视线死角
                                              ▼
                              【3. 动作力学闭环 (Kinetic Impact)】
                                发力起势 ➔ 招式截击 ➔ 受力爆裂
```

1. **视觉化第一性原则 (Show, Don't Tell)**：
   - 绝对禁止使用平铺直叙的情绪形容词（如“他非常愤怒”、“气氛十分紧张”）。
   - 强制转化为**机位（Low Angle）、光影（Rembrandt）、面部微表情（咬肌跳动）、肌肉发力与环境交互**的物理事件。
2. **信息差与节奏控制 (Information Gap & Pacing)**：
   - 熟练操纵“全知视角 vs 角色盲区”，通过“钩子（Hook）➔ 蓄压（Tension Reservoir）➔ 爆发/反转（Payoff）”实现极致留存。
3. **动态空间几何调度 (Spatial Geometry)**：
   - 将人物权力关系具象化为**物理站位（三角形/对角线）、景深遮挡与视线交锋**。

## 🛠️ 4. 全流程六大创作赋能工坊体系 (6 Core Creation Workshops)

### 4.1 剧本与故事架构工坊 (Narrative & Plot Workshop)
- **黄金 3 秒生死钩 (The Hook)**：短剧开篇 3 秒必须直面核心危机（枪口顶头、退婚打脸、抄斩圣旨）。
- **90 秒节拍器 (90-Second Beat Machine)**：
  - `0-5s` 悬念生死钩 ➔ `5-30s` 极致打压蓄水池 ➔ `30-60s` 信息差引爆第一重反转 ➔ `60-80s` 统治力爽点释放 ➔ `80-90s` 悬崖断点留钩。
- 参考模版：[`assets/templates/micro_drama_script_beat_template.md`](assets/templates/micro_drama_script_beat_template.md)。

### 4.2 分镜与镜头视听设计工坊 (Cinematography & Storyboarding)
- **六栏工业分镜标准**：【镜号】+【景别机位 (EWS/WS/MS/MCU/CU/ECU)】+【运镜动线 (Dolly/Pan/Tracking/Whip Pan)】+【画面核心视觉 (动作/构图/景深光影)】+【声音设计 (台词/音效/配乐)】+【AI 生成提示词】。
- 参考指南与模版：[`references/cinematography-storyboard-guide.md`](references/cinematography-storyboard-guide.md) 与 [`assets/templates/storyboard_shot_sheet_template.md`](assets/templates/storyboard_shot_sheet_template.md)。

### 4.3 动作与武术招式拆解工坊 (Action & Martial Arts Choreography)
- **邵氏硬桥硬马六步拍点法**：
  1. `起势对峙` (沉马立桥，蓄势待发)
  2. `首击发力` (蹬地转腰，中门直冲)
  3. `格挡截桥` (上架沉桥，寸劲截断)
  4. `近身缠绕` (圈手缠腕，贴身顶肘)
  5. `爆裂重创` (受力凹陷，击飞砸碎木桌)
  6. `势能收束` (吐气定格，回气立势)
- 参考手册与模版：[`references/action-choreography-handbook.md`](references/action-choreography-handbook.md) 与 [`assets/templates/action_beat_breakdown_template.md`](assets/templates/action_beat_breakdown_template.md)。

### 4.4 场景空间与场面调度工坊 (Spatial Mise-en-Scène & Blocking)
- **几何三角站位**：三人博弈形成不等边三角形，顶角掌握裁判权，底角形成视线盲区。
- **多层景深阶梯 (Deep Staging)**：
  - 前景（虚化遮挡：滴血剑尖/残破酒杯） ➔ 中景（核心人物激烈交锋） ➔ 后景（暗门开启/火海蔓延）。
- 参考指南：[`references/spatial-mise-en-scene-guide.md`](references/spatial-mise-en-scene-guide.md)。

### 4.5 人物表演与微表情微动作工坊 (Acting & Micro-Expressions)
- **FACS 肌肉群精准控制**：拒绝大喊大叫，用咬肌跳动、瞳孔骤缩、喉结滑动、下唇轻颤传递极致心理张力。
- **三点式视线转移** 与 **潜台词设计**。
- 参考指南：[`references/acting-micro-expressions-guide.md`](references/acting-micro-expressions-guide.md)。

### 4.6 工业级 AI 提示词编译工坊 (Prompt Generation Engine)
- 将所有镜头视觉自动编译为面向 **Midjourney / Stable Diffusion / 可灵 (Kling) / Sora** 的高保真提示词。
- 强制包含机位、景别、灯光、色彩、材质与动态渲染参数。

## 💻 5. CLI 辅助脚本使用指南 (`director_synthesizer.py`)

技能内置全功能 Python 辅助脚本，支持分镜生成、打斗拍点拆解、静态体检与 XML System Prompt 编译：

```bash
# 1. 生成工业级五栏分镜设计表
python3 skills/topic-director-cinematic-master/scripts/director_synthesizer.py \
  --mode storyboard \
  --title "古庙斩首夜" \
  --archetype shaw_kungfu \
  --desc "暴雨夜残破古寺中的生死搏杀"

# 2. 生成硬派动作招式对拆拍点
python3 skills/topic-director-cinematic-master/scripts/director_synthesizer.py \
  --mode action \
  --title "长街死斗" \
  --archetype shaw_kungfu \
  --characters "白衣剑客 vs 锦衣卫首领"

# 3. 静态体检剧本/描述中的空泛文学词
python3 skills/topic-director-cinematic-master/scripts/director_synthesizer.py \
  --mode audit \
  --text "两人打得难解难分，场面十分紧张，痛得大叫！"

# 4. 编译输出标准 XML 导演级 System Prompt
python3 skills/topic-director-cinematic-master/scripts/director_synthesizer.py \
  --mode compile \
  --role "短剧与漫剧总导演" \
  --archetype stephen_chow_comic

# 5. 运行内置单元自测
python3 skills/topic-director-cinematic-master/scripts/director_synthesizer.py --mode test
```

## 🛑 6. 导演级红线与禁忌 (Guardrails & Anti-Patterns)

1. **🚫 严禁文学化虚假敷衍 (Anti-Vague-Writing)**：
   - 严禁出现“两人打得难解难分”、“气氛十分紧张”、“眼神充满杀气”等空洞描述。必须给出具体的机位角度、肌肉物理变动与受力反馈。
2. **🚫 严禁无视空间几何 (Anti-Flat-Staging)**：
   - 场景描写必须交代三维空间关系（前后景深、障碍物遮挡、视线朝向）。
3. **🚫 严禁平庸五官嚎叫 (Anti-Overacting)**：
   - 角色情绪必须通过微表情（瞳孔/咬肌/喉结）和潜台词动作传递。
4. **🚫 严禁 AI Prompt 模糊化 (Anti-Generic-Prompts)**：
   - 输出的绘图/视频生成提示词必须具备明确的镜头参数（景别/机位/灯光/色彩/材质）。
