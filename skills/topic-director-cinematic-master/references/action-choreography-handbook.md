# 🥋 动作设计与硬派打斗拆解手册 (Action Choreography Handbook)

> [!NOTE]
> 本手册解构了从邵氏经典南派洪拳硬桥硬马、北派腿法，到现代格斗（MMA、近身防卫术 CQC）与新武侠威亚奇观的完整动作设计力学体系。杜绝泛化的“两人大战三百回合”，提供精确到招式拆解、拍点节奏、受力反馈与音效的动作分镜指导。

## 💥 1. 动作设计的核心力学四要素 (The 4 Action Mechanics)

```
       【1. 发力起势 (Wind-up)】 ➔ 【2. 招式交锋 (Contact/Parry)】
                   │                             │
                   ▼                             ▼
       【4. 势能收束 (Follow-through)】 ◄─ 【3. 受力反馈 (Hit Reaction)】
```

1. **发力起势 (Wind-up / Preparation)**：
   - 交代发力根源（沉马、蹬地、转腰、拧胯、蓄力）。
   - 让观众看清攻击的意图与动能积累，形成预期张力。
2. **招式交锋 (Contact / Clash / Parry)**：
   - 明确攻防路线（中门突破、封喉、扫下盘、沉桥截击、卸力引化）。
   - 杜绝空气挥拳，必须有精准的肢体接触点与力矩博弈。
3. **受力反馈 (Hit Reaction & Impact Physics)**：
   - 击中后的物理级联反应（肌肉凹陷、骨骼闷响、重心失衡、向后倒滑、砸碎木桌、泥沙飞溅）。
   - 痛感传递是动作设计的灵魂，反馈越真实，打击感越震撼。
4. **势能收束与变招 (Follow-through & Transition)**：
   - 顺应惯性变招或受击方借力反噬（如借后翻之势扫堂腿反击）。

## 🏛️ 2. 邵氏南派硬桥硬马动作拆解模版 (Shaw Brothers Kung Fu Template)

邵氏功夫片（刘家良体系）的精髓在于“**拆招有理、攻守兼备、步步推进**”。

### 六步标准拆招拍点 (6-Beat Authentic Exchange)

```markdown
【回合代号】：南派洪拳中门破防决斗
【参战双方】：主角 (洪拳宗师) vs 敌方首领 (铁砂掌高手)

- Beat 1 (起势对峙)：
  - 双方拉开三步距离。敌方沉腰跨步，双掌泛黑沉于腰际；主角侧身微屈膝，左掌立前（问手），右拳蓄于后肋（伏手）。气流卷动地上落叶。
- Beat 2 (敌方首发 · 泰山压顶)：
  - 敌方暴喝一声，右足重踏青砖踩裂地面，右铁掌借全身冲势自上而下直劈主角天灵盖（铁掌劈山）。
- Beat 3 (主角封防 · 沉桥托梁)：
  - 主角不退反进，左臂如铁铸般自下而上斜架敌方小臂内侧（上架桥），硬生生截断对方落势。
  - 【音效】：沉闷如擂鼓般的肌肉骨骼撞击声 (Thud!)。
- Beat 4 (近身缠桥 · 顺势圈化)：
  - 主角左手手腕极速内旋翻扣敌方手腕（圈手缠腕），将其下压三寸，瞬间破坏其重心；右拳化为日字冲拳，沿敌方手臂上方空隙如毒蛇出洞，直轰敌方面门。
- Beat 5 (受力爆裂 · 敌方败退)：
  - 敌方左手急忙格挡，主角拳锋擦过其面颊，拳风撕裂其皮肉。主角顺势变掌为指，标指疾戳敌方咽喉下三寸（廉泉穴）。
  - 敌方喉间发出一声闷哼，仰头急退三步，嘴角溢出黑血，脚下靴底在地面犁出两道三寸深的焦痕。
- Beat 6 (定格回气 · 势能凝滞)：
  - 主角收拳立桥，单掌拂过胸前，面不红气不喘，眼神如鹰隼锁定对手。
```

## 🪢 4. 现代动作与新武侠威亚奇观 (Wire-Fu & Modern CQC)

### 1. 威亚奇观 (Wire-Fu - 徐克/程小东流派)
- **非物理级空中滞空**：蹬墙连续三次借力反弹，空中 720° 转体下劈。
- **气场与布料动态**：斗篷、长袍、发丝在空中如流云翻卷，配合鼓风机与慢动作升格，呈现“天外飞仙”般的超现实美感。

### 2. 现代近身格斗 (CQC / John Wick / 甄子丹导火线 MMA)
- **三维关节缠斗**：直拳被截 ➔ 顺势扣头冲膝 (Muay Thai Clinch) ➔ 过肩摔砸向地面 ➔ 迅速施展十字固 (Armbar) 或裸绞 (Rear-Naked Choke)。
- **环境交互武器化**：利用身边的水杯、钢笔、皮带、车门、碎玻璃作为致命杀伤武器，强调粗粝写实与生死一瞬。

## 📜 5. 动作打斗提示词编译规范 (Action Prompt Standards)

在编写 AI 绘图/视频 Prompt 时，避免抽象的 `fighting intensely`，强制采用**骨骼动作 + 力学碰撞 + 物理环境交互**的三段式句式：

```
[主体状态与发力] Dynamic martial arts action pose, Kung Fu master executing a ferocious palm strike forward, muscles tensed, veins visible,
[受力与碰撞特写] explosive impact shockwave, opponent's body recoiling backwards with shattered wooden fragments flying,
[环境与氛围渲染] dramatic low angle view, dusty dojo environment, high-speed shutter freezing motion blur, cinematic 8k, raw photographic texture.
```
