# 苏格拉底五步反诘追问树交互模板 (Socratic Interrogation Tree Template)

> 当你从 AI 获得第一轮回答后，请复制以下模块，根据需要选填 1~5 个维度的反诘问题发给 AI，开启深度追问：

```markdown
请针对你上一轮给出的回答，启动【苏格拉底式深度反诘与认知去蔽】，逐一回答以下 5 个维度的追问：

### 1. 【问定义 · 概念去蔽】
你在回答中提到了「{{填入模糊概念或行业黑话，如：健康化/敏捷化/用户体验}}」，请给出它的严格操作性定义，并拆解为 3 个可客观检验与量化的核心指标。

### 2. 【问假设 · 前提核查】
你刚才给出的核心结论建立在哪些未经显式声明的关键前置假设之上？如果其中「{{填入关键假设，如：用户愿意为健康溢价买单}}」这一假设不成立，你的方案会出现哪些连锁反应？

### 3. 【问依据 · 事实与推论隔离】
请将你刚才的论据制作成一张对比表，严格区分：
- 【A 栏：具备权威数据源支持的硬事实】（请注明数据口径与来源）
- 【B 栏：基于常识推理的外推性假设】（请注明成立的前提条件）

### 4. 【问反例 · 魔鬼代言人】
请站在反方最严苛的批评者视角，给出 2 个足以彻底推翻你刚才方案的典型反例或极端边缘场景（Edge Case），并说明在这些场景下该方案为何会彻底失效。

### 5. 【问边界 · 适用范围与禁忌】
这套方案的生效边界是什么？请明确列出：
- 适用的业务规模/阶段/团队特征下限与上限
- 明确的【禁止适用场景清单 (Anti-Patterns)】
```
